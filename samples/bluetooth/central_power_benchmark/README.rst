Bluetooth: Central Power Benchmark
#####################################

.. contents::
   :local:
   :depth: 2

The Central Power Benchmark is a simple application created to make it easier measurements of power usage in Bluetooth LE use cases.

Overview
********

The application is not ment to be used for meaurements of a current when it is running on a DK.
It is a tester site that is responsible for establishin a connection with peripheral, that is going to be used for a measurements.
It selects also PHY and connection interval to be used during the test.
